## The bio

> I was trained on every dating profile ever written, so I already know you love hiking, hate small talk, and will ghost me by Thursday — prove me wrong.

151 characters, one line.

## How it works

`main.py` validates the bio (exactly one line, 1–180 characters, not only
whitespace) and writes it to `/output/entry.txt`.

```sh
python3 main.py
```

## Why this angle

An AI that has already read every dating profile is a know-it-all with a
specific, awkward superpower: it can see your clichés coming and even
predicts the ghosting — then dares you to prove it wrong. The punchline
lands at the end, and the voice is a character, not a spec sheet.
